# invitaciones

Invitación digital para la celebración de graduación de **Ing. Brandon Mauricio Noj Romero**,
Ingeniero en Ciencias y Sistemas (USAC).

🔗 https://mauricio-noj.github.io/invitaciones/

## Editar los datos

Todo el contenido (fecha, lugar, familias, fotos, tesis) está en [`js/config.js`](js/config.js).
Si un campo opcional queda vacío, su sección se oculta.

## Estructura

```
index.html          Página
css/styles.css      Estilos
js/config.js        Datos de la invitación
js/main.js          Lógica (cuenta regresiva, mapa, galería, música)
img/                Fotos
assets/musica/      Música de fondo
```
